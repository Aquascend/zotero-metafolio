# MetaFolio for Zotero

[简体中文](README.md)

When Zotero can’t find a match for a PDF, MetaFolio can read its opening pages and help you create a library item. It works with journal articles, theses and dissertations, and Chinese patents. You can check each field against the text it came from and make corrections before saving. Everything runs on your computer.

## Install

MetaFolio supports Zotero 10.0.x. Download the `.xpi` file under **Assets** on the [latest release](https://github.com/Aquascend/zotero-metafolio/releases/latest). In Zotero, open **Tools → Plugins**, click the gear icon, choose **Install Plugin From File…**, and select the downloaded file.

## Use

Right-click a PDF in your library. The add-on’s interface is currently in Chinese. Choose **用书目拾页识别 PDF 题录…** to read the PDF, then expand **查看字段依据** to see the text behind each field.

Review the details and click **创建条目** to create an item with the PDF attached. If the PDF already has a parent item, the same menu opens a read-only preview. Results depend on the page layout and text quality. Image-only scans need OCR first.
