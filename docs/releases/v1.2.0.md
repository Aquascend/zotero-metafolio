MetaFolio 1.2.0 增加了期刊文章的离线识别。选中 PDF 后，右键点「用书目拾页识别 PDF 题录…」，即可按字段查看题名、署名、期刊、日期、卷期、页码或文章号和 DOI 的依据。独立附件可以在核对后创建期刊条目，已有父条目的附件可以只读预览。

**实测范围**　在一份以医学物理为主的文库中，对期刊类型记录下的全部 167 份附件逐件回放。88 份读取 Zotero 10.0.8 的 PDF 文字，79 份只有本机全文索引。另有 3 条记录没有可测附件。出版方记录和 Crossref 仅用于开发验证，插件运行时无需联网。

| 结果 | 附件数 |
| --- | ---: |
| 读出了期刊题录 | 111 |
| 期刊文章缺少可识别的首页线索，留待人工处理 | 52 |
| 技术报告、幻灯片和补充材料，未生成期刊题录 | 4 |

在 111 份输出中，110 个题名经排版和标点归一后与公开书目记录相符。填出的 81 个 DOI、50 组完整作者名单和 107 个出版年份都与参照记录一致。部分期号只在首页印了主期号，两处期刊名称采用刊头缩写。有一篇旧 PDF 的索引把题名中的希腊字母 γ 读成了拉丁字母 c。插件会提示核对这类单字母指标。以上数字只反映这批样本。

**三个可以核对的例子**

- 《X射线CT引导的小鼠皮下肿瘤精准照射》首页的 DOI 被空格和全角符号拆开。插件复原出 `10.20173/j.cnki.ned.2024.0014`。该文件的文字层还把一位作者的姓名读错，预览会提示核对，整组作者留空。[期刊官网](https://here.cbpt.cnki.net/portal/journal/portal/client/paper/5ce0eecc6dc1d0df7f525dcdc1e156ef)
- Miles 等的论文从出版方打印页读出 `10.1016/j.ijrobp.2025.06.3883` 和 8 位作者。即使馆藏已有条目，也可以这样核对可疑的 DOI。[出版方记录](https://www.redjournal.org/article/S0360-3016%2825%2904521-3/abstract)
- Chang 等的论文从 APS 首页读出 `10.1103/pkhq-5stm`、卷 25 和文章号 `044031`，文章号的前导零得以保留。[APS 记录](https://journals.aps.org/prapplied/abstract/10.1103/pkhq-5stm)

另用文库外的两篇 APS 论文复测，两篇均正确提取了题名、期刊、卷、文章号、年份和 DOI。其中一篇的署名带有多种贡献符号，作者留空。较早的 APS 版式仍可能无法识别。[量子光学样本](https://journals.aps.org/prapplied/abstract/10.1103/PhysRevApplied.21.024032) · [热力学样本](https://journals.aps.org/prresearch/abstract/10.1103/PhysRevResearch.6.013040)

**安装**　从发布附件下载 `metafolio-1.2.0.xpi`，在 Zotero 10.0.x 的插件管理器中选择「从文件安装插件」。
