# MetaFolio 1.2.0

新增期刊文章识别。右键点击 PDF，即可从支持的期刊首页提取题名、作者、期刊名、卷期和 DOI。保存前可以逐项核对。已有条目的 PDF 也可以打开只读预览。

MetaFolio can now create journal article items. Right-click a PDF to read the title, authors, journal, volume, issue, and DOI from supported article layouts. Review the details before saving, or open a read-only preview for a PDF that already has a parent item.
