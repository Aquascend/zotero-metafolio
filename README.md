# MetaFolio for Zotero · 书目拾页

把学位论文的题名页和中国专利的扉页读成 Zotero 题录。识别在本机完成，字段旁保留原文依据，适合整理 Zotero 原生检索后留下的独立 PDF。

## 使用

在 Zotero 10.0.x 中打开「工具 → 插件」，点齿轮并选择「从文件安装插件」，打开 `metafolio-1.1.0.xpi`。此包沿用旧版「学位论文封面识别」的插件 ID，安装后会就地升级。当前通过 XPI 手动更新。

在文库里选中一个或多个 PDF，右键点「用书目拾页识别 PDF 题录…」。核对或修改字段，展开「查看字段依据」即可找到相应的页码和原文。点「创建条目」会将独立附件归入新建的父条目，父条目继承原集合。可以逐份跳过或结束。选中已有父条目的 PDF 附件可以只读预览。

**学位论文**依据题名页、学位声明和机构推荐引文识别题名、作者、授予单位、学位类型、日期和有明确归属的 DOI。支持带有这些线索的中文和英文版式，并可读取部分德国高校的学位声明。并非每份题名页都能确认全部字段。数字日期的日月顺序有歧义时会保留可核实的年份，核对窗口同时显示原文。

**中国专利**依据首页的编号栏目识别文献号、申请号、申请日、授权公告日、发明人及专利权人。发明申请公开文本上的申请公布日、申请人保存在 Zotero 的「其他」字段（Extra），以保留它们的原意。若首页同时列有对比文件或同一申请较早的公开号，识别会按本页的文献种类核对号码。[WIPO 专利著录项目编号标准 ST.9](https://www.wipo.int/documents/d/standards/docs-en-03-09-01.pdf)

插件优先使用 Zotero 自带的 PDF 阅读组件。原文件不可用时会尝试现有的本机全文索引，并在核对窗口标明来源。纯图片扫描件需要先做 OCR。解析不依赖外部数据库、AI 服务或 API 密钥。

## 开发

在项目目录运行 `node --test` 执行测试，运行 `python build.py` 生成 XPI。两者均使用标准库。测试用例是虚构的封面文字，可以随项目公开。

论文规则位于 `addon/parser.js`，专利规则位于 `addon/patent-parser.js`。两者共用 PDF 读取、字段核对和 Zotero 入库流程。发布正式版本时，可将清单中的保留域名更新地址替换成项目的 HTTPS 更新清单。
