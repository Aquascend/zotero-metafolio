# MetaFolio · 书目拾页

[English](README.en.md)

Zotero 没能为 PDF 找到条目时，可以让书目拾页读一读首页。它能识别期刊文章、学位论文和中国专利，从页面上提取题名、作者等信息。你可以对照原文修改，再保存到文库。整个过程都在本机完成。

## 安装

适用于 Zotero 10.0.x。从[发布页](https://github.com/Aquascend/zotero-metafolio/releases/latest)下载附件中的 `.xpi` 文件。在 Zotero 中打开「工具 → 插件」，点击齿轮，选择「从文件安装插件」，打开刚下载的文件。

## 使用

在文库里右键点击 PDF，选择「用书目拾页识别 PDF 题录…」。想确认某一栏是从哪里读到的，可以展开「查看字段依据」。

核对后点「创建条目」，PDF 就会附在新条目下。已经归入条目的 PDF 也可以用这个菜单只读预览。识别效果取决于首页的排版和文字质量，遇到纯图片扫描件，请先做文字识别（OCR）。
